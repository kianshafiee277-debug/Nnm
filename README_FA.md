# برنامه تیم گیمینگ IRXGG — Oxide

این پروژه یک وب‌اپ واکنش‌گرا با ظاهر مناسب موبایل است. روی اندروید از مرورگر اجرا می‌شود و می‌توانید از منوی مرورگر گزینه **Add to Home screen / افزودن به صفحه اصلی** را بزنید تا مثل برنامه باز شود. این نسخه APK اندروید نیست.

## قابلیت‌ها
- ساخت حساب و ورود با رمز عبور هش‌شده
- اولین حساب به‌صورت خودکار لیدر می‌شود
- فهرست اعضا و مدیریت نقش اعضا توسط لیدر
- پیام‌های تیم (ذخیره در سرور؛ بدون اتصال زنده/وب‌سوکت)
- ثبت برنامه حمله، دفاع و تمرین
- فهرست متحدها و دشمن‌ها
- ثبت کیل، دث و اسیست
- ذخیره داده‌ها در `data/db.json`

## اجرا روی کامپیوتر
نیاز به Node.js نسخه 18 یا جدیدتر دارید.

1. فایل ZIP را استخراج کنید.
2. ترمینال را در پوشه پروژه باز کنید.
3. اجرا کنید:
   ```bash
   npm start
   ```
4. مرورگر را باز کنید و وارد `http://localhost:3000` شوید.
5. اولین حسابی که می‌سازید لیدر خواهد بود؛ نام کاربری فقط حروف انگلیسی، عدد و `_` و طول ۳ تا ۲۴ کاراکتر؛ رمز حداقل ۸ کاراکتر.

## اجرا روی گوشی اندروید
برای اجرای خود سرور به محیطی مانند Termux و نصب Node.js نیاز دارید. پس از نصب Node.js در Termux:
```bash
cd مسیر/پوشه/IRXGG_Team_App
npm start
```
سپس در همان گوشی `http://127.0.0.1:3000` را باز کنید. اجرای دائمی روی گوشی نیازمند باز ماندن سرویس/تنظیمات مناسب است. برای دسترسی دیگر اعضا، باید سرور روی یک هاست یا VPS قرار بگیرد؛ `localhost` فقط همان دستگاه است.

## انتشار روی اینترنت
روی هاست/VPS دارای Node.js:
1. پروژه را آپلود کنید.
2. `npm start` را اجرا کنید یا یک process manager استفاده کنید.
3. دامنه و HTTPS را با reverse proxy (مثلاً Nginx) تنظیم کنید.
4. از پوشه `data` نسخه پشتیبان منظم بگیرید.
5. دسترسی نوشتن به `data/db.json` را فقط به کاربر سرویس بدهید.

## نکات مهم پیش از استفاده واقعی
- این پروژه نسخه آغازین است؛ قبل از استفاده عمومی، HTTPS اجباری، محدودیت تلاش ورود، سیاست بکاپ و پایش خطا اضافه کنید.
- برای استفاده همزمان چند نفر، بهتر است JSON به PostgreSQL/SQLite منتقل شود. در نسخه فعلی نوشتن فایل برای تیم کوچک و تست مناسب است، نه بار سنگین.
- چت زنده نیست؛ پیام‌ها هنگام بارگذاری/تازه‌سازی مجدد دریافت می‌شوند.
- اطلاعات ثبت‌شده در این نسخه داخل فایل `data/db.json` قرار می‌گیرند؛ این فایل را عمومی نکنید.
- این نسخه به سرویس رسمی یا API بازی Oxide متصل نیست و آمارها دستی وارد می‌شوند.
- نقش لیدر به اولین حساب ثبت‌نام‌شده داده می‌شود؛ هنگام راه‌اندازی عمومی، ثبت‌نام را محدود کنید تا حساب اول را فرد مورداعتماد بسازد.
